Anmelden

Adresse im Browser eingeben:

pcelektro.de/pflege

Passwort eingeben, auf "Anmelden" klicken. Das war es. Kein Benutzername, keine Installation, kein Programm auf dem Rechner.

Ihr Passwort steht auf dem Blatt, das Sie bei der Übergabe bekommen haben. Schreiben Sie es nicht auf einen Zettel am Monitor.

Sie bleiben acht Stunden angemeldet. Danach fragt die Seite noch einmal.

Etwas ändern

Nach dem Anmelden sehen Sie oben die Reiter der vier Seiten: Startseite, Impressum, Datenschutz, Danke-Seite. Meist brauchen Sie nur die Startseite.

Darunter stehen die Felder, die Sie ändern können:

EinleitungstextDie ersten Sätze ganz oben.

Text ändern, unten auf "Speichern" klicken, fertig. Die Website ist sofort geändert. Rufen Sie sie auf und sehen Sie nach.

Sie müssen nichts doppelt ändern. Ihre Telefonnummer steht achtmal auf der Seite, im Text und in den Nummern zum Antippen. Sie ändern sie einmal, und alle acht Stellen ändern sich mit. Dasselbe gilt für die Öffnungszeiten.

Ein Foto austauschen

Beim Feld "Bild aus dem Betrieb" auf "Datei auswählen" klicken, ein Foto vom Rechner oder vom Handy wählen, speichern.

Das Foto darf so groß sein, wie es aus der Kamera kommt. Zu große Bilder werden beim Hochladen automatisch verkleinert, damit die Website schnell bleibt. Sie müssen nichts vorbereiten.

Angenommen werden JPG und PNG. Andere Dateien weist die Seite ab.

Wenn etwas schiefgeht

Ganz unten steht "Frühere Stände". Dort liegen die letzten Fassungen jeder Seite mit Datum und Uhrzeit, die neueste oben. Auf "zurückholen" klicken, und die Seite ist wieder so, wie sie zu diesem Zeitpunkt war.

Auch das Zurückholen können Sie rückgängig machen. Der Stand, der gerade galt, wird vorher gesichert und steht danach oben in der Liste.

Von jeder Seite bleiben die letzten zwanzig Fassungen liegen. Zur Auswahl stehen die letzten acht.

Sie können also nichts kaputt machen. Probieren Sie ruhig etwas aus.

Zwei Felder lassen sich nicht leeren

Telefonnummer und E-Mail-Adresse. Wenn Sie eines davon leeren und speichern, kommt eine Meldung, und es wird nichts gespeichert. Das ist Absicht: Eine Website ohne Telefonnummer wäre der teuerste Tippfehler.

Passwort ändern

Im Pflegebereich ganz unten unter "Passwort ändern": das bisherige Passwort, das neue, das neue noch einmal. Mindestens acht Zeichen.

Ändern Sie es, sobald jemand aus dem Betrieb geht, der es kannte.

Ihr Passwort steht nirgends im Klartext auf dem Server, auch nicht in einer Datei, die wir lesen könnten. Wenn Sie es vergessen, kann es niemand nachschlagen, es muss neu gesetzt werden. Rufen Sie uns dann an.

Was Sie nicht selbst ändern können

Den Aufbau der Seite, die Abschnitte, die Leistungsliste, die Referenzen, das Impressum, die Farben. Dafür rufen Sie uns an.

Das ist keine Einschränkung aus Bequemlichkeit. Was Sie ändern können, ist genau das, was sich im Betrieb ändert: Nummer, Zeiten, Hinweise, Stellen, Fotos. Alles andere bleibt so, wie es geprüft und freigegeben wurde.
